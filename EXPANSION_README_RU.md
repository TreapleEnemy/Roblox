# GladeSlayer — «Острова пепла»

Полные исходники расширения и собранный плейс. Нужен Roblox Studio. Внешние изображения, AnimationId и дополнительные библиотеки не нужны.

## Быстрый запуск

1. Откройте `dist/GladeSlayer.rbxlx` через File → Open from File в Roblox Studio.
2. Нажмите Play. Карта строится сервером при запуске; в режиме Edit до запуска её не видно.
3. Для переноса в существующий плейс сначала сделайте резервную копию. Замените соответствующие папки скриптов целиком по `default.project.json`, а не добавляйте второй Main рядом с первым. Альтернатива — Rojo, как в README.md.
4. Оригинальные клавиши сохранены: B — инвентарь, C — прокачка, E — торговец/портал, ЛКМ — атака. На сенсорном экране есть кнопка атаки.
5. Для постоянных сохранений опубликуйте плейс и настройте доступ к API в Studio. Studio использует прежний суффикс `_Studio`; имя боевого DataStore не менялось.

## Содержание

- Стартовый остров: дополнительные кристаллы, мшистые валуны, папоротники, фонари, дорожки к порталам, полки с бутылками и ящики у существующих лавок. Освещение мягче: поздний день, Atmosphere, Bloom, ColorCorrection и SunRays. Существующие NPC, спавн и зоны слизней/Стражей сохранены.
- «Затерянные пески»: уровень 15+, песок, дюны, кактусы, храмовые колонны, ступенчатая пирамида. Песчаный часовой и Хранитель солнца.
- «Пепельная корона»: уровень 35+, базальт, светящиеся кристаллы, лавовые каналы, руины и арена босса. Рыцарь углей и Обсидиановый страж. Лава декоративная, без скрытого урона.
- Шесть физических порталов: с Поляны на оба острова, с каждого нового острова на Поляну и на другой новый остров. Остров также выбирается в экранном меню. Уровень, жизнь, бой и перезарядку проверяет сервер.
- Телепорт бесплатный, перезарядка 5 секунд; после нанесения/получения урона блокируется на 8 секунд. Возрождение по-прежнему на Поляне.
- Все новые существа имеют суставные риги, покой/дыхание, шаг, замах, реакцию на попадание и падение с рассыпающимися локальными осколками. Используются TweenService и Motor6D.C0, без загружаемых анимаций.
- Босс «Владыка пепла»: 24 000 ХП; крупная модель; BillboardGui и экранный Boss Bar в радиусе 120 studs. Обычный удар и AoE с серверным красным кругом, предупреждением 1,65 секунды и проверкой позиции в момент попадания.
- Вторая фаза при 50% ХП: быстрее передвигается, обычный урон ×1,25, AoE-урон ×1,3, радиус AoE ×1,2 и меньшая пауза между AoE. После 10 секунд без цели босс полностью восстанавливается и сбрасывает вклад в награду. Респаун через 120 секунд.
- Награда босса: 3500–5000 монет до баффа, 4500 XP, ядро углей гарантировано, обсидиановый меч 45%, «Катаклизм» 12%. Старая система распределения награды сохранена: убийца и участники с вкладом от 25% ХП.
- Новые предметы: солнечный осколок, царский скарабей, пылающее ядро, обсидиановая реликвия, клинок дюн, обсидиановый меч и легендарный «Катаклизм» (+230 урона, +150 ХП).
- Экранные кнопки: Inventory, Stats, Shop, Teleports; наведение/нажатие анимируются, клик использует встроенный `rbxasset://sounds/electronicpingshort.wav`.
- Иконки строятся из многослойных Frame, UICorner, UIStroke и UIGradient; оружие, броня, амулеты, зелья, материалы и статы не зависят от внешних картинок. Общий вид значков соответствует типу предмета, цвет — редкости.
- Инвентарь: UIGridLayout, слоты, экипировка/снятие одним нажатием, описание при наведении или выборе, фильтры «все / экипировка / зелья / мусор / редкие+». Панели масштабируются под размер окна.
- Удаление мусора требует повторного нажатия в течение 4 секунд и не даёт монет. Удаляются только Junk и помеченные Junk старые вещи. Надетый экземпляр, редкие материалы, зелья и легендарные вещи защищены. Прежняя продажа всего хлама у Скупщика осталась отдельной механикой.

## Магазин и Robux

Покупки за игровые монеты работают через прежний серверный EconomyService у Кузнеца. Кнопка Shop открывает информационный экран и позволяет открыть кузницу, если персонаж рядом. Проверка дистанции не обходится.

Robux-покупки по умолчанию отключены: в приложенных файлах нет реальных ID продуктов или пропусков вашего опыта. `Config.GamePasses = {}` — осознанная настройка, а не заглушка обработчика. При необходимости добавьте существующий **донатный пропуск без игровых бонусов**, например `{ Id = 123456789, Name = "Поддержать игру" }`, заменив ID своим реальным ID. После настройки кнопка вызовет стандартное окно покупки Roblox. Не указывайте чужие ID. Эта поддержка не выдаёт валюту и не обещает бонусы; для монет за Robux нужен отдельный проверенный ProcessReceipt с идемпотентной выдачей, который в этом расширении не заявлен.

## Совместимость

- Сохранены имена прежних модулей, публичные сигнатуры, существующие RemoteEvent/RemoteFunction, ключи предметов и мобов, SchemaVersion = 1 и DataStoreName.
- Новые Request-действия: Teleport, DiscardJunk. Новый FX: BossImpact. Новые поля Boss/Phase/MobDead — атрибуты моделей, не миграция профиля.
- DataService, CharacterService, NPCService, Health и исходная серверная боёвка не переписаны. Расширение вносит дополнения в Config/Rules/Models/Animator/WorldBuilder/MobService/EconomyService/клиентский UI и Effects.
- Добавлены ExpansionWorld, TravelService и Icons. Старый Main запускает те же сервисы и дополнительно подключает TravelService. Сборщик автоматически включает новые модули.
- Список сохранённых ключей и точный перечень изменённых файлов см. `CHANGELOG_EXPANSION.md`.
- Совместимость структуры сохранений и интерфейсов проверена офлайн. Полная совместимость игрового поведения требует регрессии в Studio; она не гарантируется без этого теста.

## Проверки и их пределы

В этой среде Roblox Studio нет, официальный Luau CLI недоступен, загрузка CLI заблокирована DNS. Не утверждается, что игра прошла официальный компилятор/анализатор Luau, визуальную проверку Studio, реальную физику, сеть, монетизацию или DataStore.

Фактически выполнены:
- разбор всех файлов Lua 5.4-парсером: код написан в совместимом подмножестве Luau;
- статическая проверка зависимостей и соответствия Request/FX;
- 244 проверки чистых правил/конфига, включая прежние тесты;
- 98 проверок на тестовых объектах: создание моделей/суставов/предметов, порталов, ограничения телепортов, спавн 28 мобов, вторая фаза, предупреждение AoE, уклонение, отмена урона после смерти босса, награда, создание и открытие панелей UI;
- чтение собранного rbxlx XML-парсером и точное сравнение каждого упакованного скрипта с исходником;
- проверка целостности финального ZIP.

Тестовые объекты не воспроизводят API Roblox полностью и не симулируют физику/рендер. Их успешное выполнение не означает, что визуальная QA пройдена. Итог и ограничения записаны в VERIFY_REPORT.txt.

### Повторная сборка

С официальными `luau`, `luau-compile`, `luau-analyze` в PATH:

```
python tools/verify.py
python tools/build.py
```

В Linux с доступной liblua 5.4 (ограниченная переносимая проверка):

```
python tools/portable_verify.py
python tools/build.py --portable
```

Параметр `--portable` выбирается явно и не маскирует отсутствие официальной проверки. На Windows без liblua используйте официальный Luau CLI.

## Обязательная приёмка в Studio

1. Play: проверьте Output на сервере и клиенте; отсутствие ошибок загрузки и сборки мира.
2. На первом уровне: удар, прокачка, лут слизней, оба NPC, покупка/продажа, B/C и сенсорная кнопка атаки.
3. Профиль уровня 14 не проходит в пустыню; 15 проходит. 34 не проходит на вулкан; 35 проходит. Сервер отклоняет поддельное действие с неверным ID острова.
4. Проверьте отсутствие застревания новых мобов, положение корней и ног, доступность попадания мечом/кулаками по ногам босса, размеры анимаций.
5. Два клиента: общий босс, синхронный красный круг, попадание только внутри круга, вторая фаза, смерть во время AoE и награды по вкладу.
6. Device Emulator: портрет/ландшафт, кнопки, прокрутка инвентаря, шрифт, описания, экранный Boss Bar и отсутствие перекрытий. Визуальное качество не проверялось в Roblox-рендерере.
7. Экипируйте OldSword при двух экземплярах; удаление мусора оставляет надетый. Редкие материалы и Cataclysm остаются. Продажа у Скупщика по-прежнему платит монеты.
8. Опубликованный тестовый сервер: повторный вход с сохранением новых предметов, конкурирующие сессии, выход во время боя, переподключение и длительная игра.

Для ускоренной проверки уровней используйте только локальную серверную Command Bar/отладчик Studio и профиль DataService из запущенного сервера. В проект намеренно не добавлена общедоступная команда выдачи уровней или валюты.
