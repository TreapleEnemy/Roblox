# GladeSlayer / «Охотник Поляны»

Прототип RPG в жанре Slayer/Simulator для Roblox. Всё создаётся кодом: карта, освещение, мобы, NPC, оружие, анимации и интерфейс. Внешние ассеты (rbxassetid) не используются.

## Запуск за 1 минуту

**Вариант A — готовый плейс (без Rojo)**
1. Открой `dist/GladeSlayer.rbxlx` в Roblox Studio (File → Open from File).
2. Нажми **Play** (F5). При старте сервер сам строит поляну, руины, лавки, мобов и NPC.
3. Чтобы прогресс сохранялся, опубликуй плейс (File → Publish to Roblox) и включи Game Settings → Security → *Enable Studio Access to API Services*. Без этого игра работает с хранилищем в памяти: прогресс живёт только в течение сессии, ошибок не будет.

**Вариант B — Rojo**
```
rojo serve default.project.json
```
В Studio: плагин Rojo → Connect. Дерево проекта:

| Папка | Куда попадает в Studio |
|---|---|
| `src/shared` | `ReplicatedStorage.GladeSlayer` (Config, Rules, Models, Animator; папку Remotes создаёт сервер) |
| `src/server` | `ServerScriptService.GladeSlayerServer` (Main + сервисы) |
| `src/client` | `StarterPlayer.StarterPlayerScripts.GladeSlayerClient` (Main, UI, Effects) |
| `src/character` | `StarterPlayer.StarterCharacterScripts` (пустой `Health` — отключает стандартный реген) |

## Управление
- **ЛКМ / тап / R2** — удар. Кулаками: чередуются левый и правый хук. С мечом: два взмаха.
- **I** — инвентарь, **K** — прокачка, **J** — подземелья, **T** — телепорты и магазин (старые **B**/**C** тоже работают). **E** — NPC, порталы, вход в подземелья. Подробности обновления — `UPDATE3_README_RU.md`.
- **E** у Скупщика (слева на рынке) или у Кузнеца (справа) — открыть магазин. Если отойти от NPC, окно закроется.

## Игровой цикл
Старт без оружия → бьёшь Лесных Слизней на поляне, позже Стражей у каменных руин на севере → выпадают монеты, опыт, хлам, «Ржавый меч» и снаряжение нищего уровня → за уровни дают очки навыков, их тратишь на Урон, Макс. ХП, Реген и Скорость → хлам продаёшь Скупщику (поштучно или «Продать весь хлам») → у Кузнеца покупаешь оружие, броню и зелья (x2 монеты, +50% урона, +опыт). Весь баланс лежит в `src/shared/Config.luau`.

## Архитектура и защита
- **Сервер** (единственный источник правды): DataService (DataStore, повторные попытки, аренда сессии, автосейв, сохранение при выходе и при `BindToClose`), CharacterService (статы → Humanoid, реген, 3D-снаряжение), MobService (ИИ, агро и возврат на место, респаун, награды), CombatService (хитбокс), EconomyService (покупка, продажа, экипировка, зелья), NPCService (ProximityPrompt), WorldBuilder (карта и Lighting/Atmosphere).
- **Rules** — чистая логика без Roblox API. Её покрывают юнит-тесты `tests/rules_spec.luau`.
- **Античит:**
  - урон считает только сервер;
  - кулдаун проверяется с допуском;
  - дистанция и хитбокс считаются от серверной позиции персонажа;
  - для каждого игрока свой лимит частоты запросов (token bucket) для Attack и Request;
  - все аргументы проверяются по типу и белому списку;
  - монеты, предметы и очки проверяются на сервере;
  - магазин работает, только если игрок стоит у NPC;
  - надетые вещи продать нельзя.
- **Клиент** только рисует: UI (HUD, прокачка, инвентарь, магазины, тосты), Effects (Motor6D-анимации через Animator, всплывающие цифры урона на BillboardGui, вспышка Highlight, тряска камеры, частицы).

## Проверка без Studio
```
python tools/verify.py   # синтаксис (luau-compile), глобалы (luau-analyze), зависимости, протокол FX/Request, юнит-тесты
python tools/build.py    # verify + сборка dist/GladeSlayer.rbxlx + dist/GladeSlayer_src.zip
```
Нужны Python 3.10+ и [Luau CLI](https://github.com/luau-lang/luau/releases) (`luau`, `luau-compile`, `luau-analyze`) в PATH или в `../.temp/luau`. Результат последней проверки лежит в `VERIFY_REPORT.txt`.

## Происхождение кода (восстановление)
- Без изменений перенесены из восстановленного архива: `Config` (баланс), `Animator`, `Main.server`. `Rules`, `Models` и сервисы собраны из фрагментов и истории правок (`tools/import_recovered.py`); имена модулей и сигнатуры функций сохранены.
- Написано заново, потому что в архиве не было кода: тело `CombatService.resolve`, обработчики `EconomyService`, `Health`, `client/Effects`, `client/UI`, `client/Main`, а также недостающие части сервисов.
- Старая версия Astra не используется.

## Что НЕ проверено в Roblox Studio
Окружения Studio не было. Не проверялись:
- визуал карты, моделей и UI (размеры, наложения, читаемость);
- поведение и плавность анимаций Motor6D на R15 и R6;
- физика мобов: Humanoid:MoveTo, застревания, ownership;
- работа реального DataStore после публикации (лимиты, аренда сессии между серверами);
- ProximityPrompt, сенсорное управление, сетевые задержки и реальный баланс по ощущениям.

При первом запуске смотри окно Output: ошибки скриптов будут там.
